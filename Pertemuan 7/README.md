# Pertemuan 7 - Memory Management

## Materi
- Pengelolaan memori pada Java.
- Reference Variable.
- Object Reference.
- Penggunaan nilai `null`.

## File Program
- `MemoryManagement.java`

## Deskripsi
Program ini mempelajari cara Java mengelola objek di dalam memori. Pembahasan mencakup reference variable, penggunaan beberapa referensi terhadap objek yang sama, serta pemberian nilai `null` pada variabel referensi.
