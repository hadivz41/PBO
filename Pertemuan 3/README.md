# Pertemuan 3 - Control Statement

## Materi
- Percabangan `if-else`.
- Percabangan `switch-case`.

## Deskripsi
Program ini menerapkan control statement untuk mengatur alur program. Menggunakan percabangan untuk menentukan kondisi dan pilihan unit PlayStation, serta perulangan untuk menampilkan daftar unit yang tersedia.
