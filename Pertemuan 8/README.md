# Pertemuan 8 - Inheritance (Basic)

## Materi
- Pengertian Inheritance.
- Superclass dan Subclass.
- Keyword `extends`.
- Keyword `super`.

## File Program
- `RentalPS.java`

## Deskripsi
Pada pertemuan ini program Rental PlayStation mulai menerapkan konsep inheritance. Class `Member` dibuat sebagai subclass yang mewarisi atribut dan method dari superclass `Pelanggan`. Dengan konsep ini, class turunan dapat menggunakan kembali fitur yang sudah tersedia pada class induk.
