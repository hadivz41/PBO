# Pertemuan 4 - Method

## Materi
- Pengertian dan penggunaan method.
- Parameter dan nilai kembalian.

## File Program

## Deskripsi
Pada pertemuan ini mulai dikembangkan program Rental PlayStation dengan menggunakan method `hitungBiaya()` untuk menghitung biaya penyewaan berdasarkan tarif dan durasi rental. Penggunaan method membantu membuat kode lebih terstruktur dan mengurangi penulisan kode berulang.
