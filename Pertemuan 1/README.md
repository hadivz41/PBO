# Pertemuan 1 - Pengenalan OOP

## Materi
- Pengenalan Object Oriented Programming (OOP).
- Pengertian Class dan Object.
- Pengenalan Atribut dan Method.

## File Program

Program sederhana untuk memahami konsep dasar OOP dengan menggunakan class `UnitPS` sebagai contoh objek. Program ini memperkenalkan atribut seperti nama dan tarif serta method untuk menampilkan informasi unit PlayStation.
