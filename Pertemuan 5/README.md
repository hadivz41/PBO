# Pertemuan 5 - Encapsulation

## Materi
- Pengertian Encapsulation.
- Access Modifier.
- Penggunaan atribut `private`.
- Getter dan Setter.

## File Program
- `RentalPS.java`

## Deskripsi
Pada pertemuan ini program Rental PlayStation dikembangkan dengan menerapkan konsep encapsulation. Atribut pada class dibuat menggunakan access modifier `private` dan diakses melalui method getter maupun setter untuk menjaga keamanan serta mengontrol perubahan data.
