# Pertemuan 9 - Inheritance (Hierarchical)

## Materi
- Hierarchical Inheritance.
- Superclass dan Subclass.
- Method Overriding.
- Penggunaan `@Override`.

## File Program
- `Pelanggan.java`
- `Member.java`
- `NonMember.java`
- `RentalPS.java`

## Deskripsi
Pada pertemuan ini program Rental PlayStation dikembangkan menggunakan Hierarchical Inheritance. Class `Pelanggan` berperan sebagai superclass, sedangkan class `Member` dan `NonMember` menjadi subclass.

Kedua subclass memiliki perilaku berbeda melalui method overriding pada method `getDiskon()`. Member mendapatkan diskon sebesar 5%, sedangkan NonMember tidak mendapatkan diskon.

Penerapan ini membuat program lebih terstruktur dan menunjukkan penggunaan inheritance untuk membedakan jenis pelanggan.
